# المرحلة 3 — التصليب والتسليم والتحضير للمقابلة

### P3-LEAD-01 · مراجعة نهائية مستقلة
- المالك: Lead (مراجعة بعدسات منفصلة: أمان، تزامن، مطابقة العقد، جودة الاختبارات)
- معايير القبول: تقرير مجمّع في `docs/review-<date>.md`؛ كل High/Critical مُصلح بـ PR؛ Medium إما مُصلح أو موثق كدَين تقني مع سبب.

### P3-LEAD-02 · تشغيل من الصفر
- الخطوات: استنساخ نظيف في مجلد جديد ⇒ `cp .env.example .env && make bootstrap && make up` ⇒ `make verify && make demo-r1 && make demo-r2 && make race-test`.
- معايير القبول: كل شيء أخضر دون أي خطوة يدوية غير موثقة؛ الزمن مُسجل في README.

### P3-LEAD-03 · الوثائق النهائية
- الخطوات: README (التشغيل، المعمارية المختصرة مع مخطط، الحسابات، روابط Swagger/Mailpit، أوامر العرض)؛ تحديث `docs/08-interview-prep.md` بمسارات الملفات والاختبارات الحقيقية لكل إجابة؛ تحديث ADRs بأي قرار استُجد.
- معايير القبول: كل سؤال في `08` يشير إلى ملف/اختبار موجود فعلاً (سكربت يتحقق من وجود المسارات).

### P3-ALL-01 · بروفة المقابلة
- الخطوات: كل عضو يُسأل أسئلة عشوائية عن **أجزاء زميله**، ويشغّل العرض بنفسه دون مساعدة.
- معايير القبول: كل عضو يشرح PROOF-R1-1/2 و PROOF-R2-1/2 ويشغلها، ويجيب عن 10 أسئلة عشوائية من `08`.

### P3-LEAD-04 · الاستعداد للمتطلب 3
- الخطوات: قائمة "نقاط الدخول" للتخزين المؤقت (ProductCatalog، GetStock، القوائم)، قياسات أساسية أولية بـ k6 (p95 لـ `GET /products` و `POST /orders`) محفوظة في `docs/baseline-perf.md` للمقارنة لاحقاً.
