## 1. ما أُنجز وأُثبت (`make demo-r5` — 12 فحصاً)
| # | ماذا | كيف | الإثبات |
|---|---|---|---|
| 1 | عدة نسخ من الـ API خلف nginx | `make scale API=3`: Docker DNS يعيد عنواناً لكل نسخة، و `edge` يدور بينها (`resolver … valid=10s`) | 45 طلباً توزعت على 3 نسخ |
| 2 | توقف نسخة لا يُفشل طلباً | `fastcgi_next_upstream error timeout` + مهلة اتصال 1 ث: النسخة التي لا تُوصَل تُتخطى | 60 من 60 طلباً نجحت ونسخة تُوقَف أثناءها |
| 3 | عدة عمّال على طابور واحد | `make scale MAIL_WORKERS=2`: مستهلكان متنافسان على `notifications.mail` | 4 طلبات ← 4 رسائل بريد، بلا تكرار |
| 4 | من خدم كل طلب | سجل `edge` (JSON) فيه الحقل `upstream` | `make logs S=edge` |

لماذا يعمل بلا تغيير في الكود: الـ API بلا حالة (JWT، لا sessions)؛ الكاش وحدود المحاولات و read-your-writes في Redis مشترك؛ الصور ومفاتيح JWT على volumes مشتركة؛ العامل idempotent (المتطلب 4)؛ و `outbox:relay` يقفل الصفوف بـ `SKIP LOCKED`.

لا يُعاد تنفيذ طلب غير idempotent: nginx لا يعيد إرسال POST/PATCH/PUT وصل إلى نسخة؛ يُعاد فقط ما لم يُفتح له اتصال.

## 2. ما لم يُنجز (ينتظر الورقة)
| الموضوع | الوضع الآن | ما قد يُطلب |
|---|---|---|
| خادم WebSocket (`reverb`) | نسخة واحدة | تعدد النسخ عبر Redis (`scaling.enabled`) + توزيع اتصالات WebSocket |
| `scheduler` | نسخة واحدة (آمن أن يتعدد بفضل `SKIP LOCKED`، لكنه غير مجرَّب) | — |
| `edge` (nginx) | نسخة واحدة = نقطة فشل وحيدة | موزّع أحمال أمامه، أو نسختان |
| قواعد البيانات و Redis و RabbitMQ | نسخة كتابة واحدة لكل منها (+ نسخة قراءة لـ Postgres من المتطلب 3) | failover، pooling (pgbouncer)، cluster |
| خدمة المخزون (Spring) | نسخة واحدة | عدة نسخ + توزيع gRPC (اتصال HTTP/2 طويل: يحتاج توزيعاً على مستوى الطلب) |
| خوارزمية التوزيع | دوران على عناوين DNS (ليس round-robin صارماً ولا least-connections) | `upstream` ثابت بخوارزمية محددة و health checks |
| اختبار حمل يثبت الفائدة | غير موجود | k6: نسخة واحدة مقابل ثلاث (throughput / p95) |
| التوسع التلقائي | غير موجود | — |

## 3. التجربة
```bash
make scale API=3 MAIL_WORKERS=2   # تشغيل النسخ
make ps                           # api-1, api-2, api-3
make demo-r5                      # الإثبات الآلي (يعيد كل شيء لنسخة واحدة في آخره)
make scale                        # العودة إلى نسخة واحدة يدوياً
```
